# Movie_ticket_booking_system
In this web application there is mainly three modules User module, Theatre module and Administrator module. This application helps the common men to know which film is running in different theatres. They can know cast and crew, trailer and such information related to films. The scope of this project involves the capability to provide efficient, reliable and secure software to speed up the developments in film Industry. 
It is developed using PHP, HTML, CSS, JavaScript, Bootstrap, SQL
